# References

This pilot builds on [RAGEN](https://github.com/RAGEN-AI/RAGEN) and adapts
[VAGEN](https://github.com/mll-lab-nu/VAGEN) to text grids. It is not an exact
VAGEN reproduction. Repository licensing is retained in [LICENSE](../LICENSE).
